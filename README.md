# CONNECTION / INVITATION

GitHub Pages용 정적 웹사이트입니다.

## 배포 방법

1. `index.html`과 `assets/` 폴더를 GitHub 저장소의 최상위에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/ (root)`로 저장합니다.
5. 잠시 후 생성된 GitHub Pages 주소로 접속합니다.

`index.html`과 `assets/` 폴더는 반드시 같은 위치에 있어야 이미지가 표시됩니다.
